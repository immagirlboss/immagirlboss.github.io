01 / Personalization research

Digital Twin

GitHub ↗

Adapting a language model to personal conversational style.

A local personal-response system comparing system prompting, retrieval, LoRA, and a multimodal prefix adapter around frozen Qwen2.5.

Message pairs → Retrieve + rerank → Qwen + adapter → Compare responses
Python / Qwen2.5 / FAISS / PEFT
View projectClose projectPictures & technical notes
Implementation & scope

The retrieval path embeds training prompts, retrieves 20 candidates, then uses a CrossEncoder to rerank and retain up to three examples behind a confidence gate. A separate LoRA adapter and an experimental text-and-Spotify prefix adapter provide comparison paths.

Latest validation experiment

A V3 threshold sweep compared raw retrieval, reranking, and confidence gating on a fixed 10-record validation subset with Groq-based judging. LoRA + reranked RAG without a gate scored 1.68 overall, versus 1.58 for LoRA + raw RAG and 1.49 for LoRA-only. An exploratory gate threshold of 0.25 used retrieval on 80% of records and scored 1.64. These preliminary validation results require a held-out comparison to assess generalization.

Research status: the system-prompted baseline is the default demo. Prefix generation remains inconsistent on unseen prompts; historical prefix scores include target-response leakage and are not evidence of generalization.

02 / A closer look

A personal model.
A question of evaluation.

Digital Twin explores how a language model can adapt to someone’s conversational style.

The work spans data preparation, retrieval, lightweight adapters, and a local comparison interface. System prompting, RAG, LoRA, and an experimental multimodal prefix adapter provide different routes to personalization.

Technical decision
Retrieve on historical prompts, then rerank and gate examples before generation.
What the experiment revealed
The prefix adapter remains inconsistent on unseen prompts. Historical prefix benchmarks contain target-response leakage; the system-prompted baseline remains the default demo.
