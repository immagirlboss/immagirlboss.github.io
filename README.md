# Akbota Kengeskhan — Portfolio

Static portfolio prepared for GitHub Pages. No build step or dependencies.

## Publish

Publish the main branch from the repository root using GitHub Pages. For the profile website, use the repository name `immagirlboss.github.io`.

## Update images

- Replace the `.portrait` placeholder in `index.html` with an image element when the portrait is ready.
- Project visuals are grouped in `.visual` elements. Replace a cover with an image using the pattern already used by MangaLens.
- Store images in `assets/` and use relative paths.

The decorative spider lily rotates once every 60 seconds. The footer button pauses it, and reduced-motion preferences disable animation.
